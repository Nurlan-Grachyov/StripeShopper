# Django + Stripe Payment System

## Описание
Это проект, демонстрирующий интеграцию Django с платежной системой Stripe. Он позволяет создавать товары (`Item`), отображать их и осуществлять оплату через Stripe Checkout с помощью API.

Проект включает:
- Модель `Item` с полями: `name`, `description`, `price`.
- API эндпоинты:
  - `GET /buy/{id}` — создание Stripe сессии для выбранного товара.
  - `GET /item/{id}` — отображение страницы товара с кнопкой для оплаты.
- Простая HTML-страница с интеграцией Stripe.js для редиректа на Checkout.

## Бонусные задачи
- Использование переменных окружения для хранения ключей Stripe.
- Просмотр моделей через Django Admin.
- Реализация модели `Order`, объединяющей несколько `Item` и оплату их общего содержимого.

## Установка и запуск

### Требования
- Python 3.8 или выше
- Poetry

### Установка зависимостей
1. Клонируйте репозиторий:
```bash
git clone https://github.com/Nurlan-Grachyov/StripeShopper.git
cd StripeShopper
```

Установите зависимости с помощью Poetry:
```
poetry install
```
Активируйте виртуальное окружение:

```
poetry shell
```
Выполните миграции:
```
python manage.py makemigrations
python manage.py migrate
```
Создайте суперпользователя для доступа к админке:
````
python manage.py admin
````
Настройте переменные окружения:<br>
Создайте файл .env 

Запустите сервер разработки:
````
python manage.py runserver
````
### Использование<br>
Перейдите по адресу http://127.0.0.1:8000/admin, чтобы управлять моделями.<br>
Создавайте товары (Item) и заказы (Order).<br>
Посмотрите страницу товара по адресу /item/{id}.<br>
Нажмите кнопку "Buy" — произойдет редирект на Stripe Checkout для оплаты.<br>

### Дополнительная информация<br>
Для тестирования используйте тестовые карты Stripe.<br>
Для безопасного хранения ключей используйте переменные окружения.<br>
